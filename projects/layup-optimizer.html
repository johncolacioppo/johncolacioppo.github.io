C(Argon) Layup Optimizer

A Python pipeline that sets up, solves and compares composite layups in ANSYS without clicking through every one by hand.

Context
Personal project for UConn FSAE
Timeline
2026–present
First target
Aero wing
Tools
Python, ANSYS Workbench, ACP

Why I built it

Working on the anti-intrusion plate showed me how slow it is to set up a layup in ACP, solve it and compare it with the last one. Every new stacking sequence meant repeating the same steps. I wanted a tool that could run those studies for me and apply the same method to any composite part on the car.

How it works

The whole pipeline starts from one script, run_pipeline.py, which drives ANSYS Workbench and ACP.

  1. Load material properties from my own library of XML material definitions.
  2. Generate the candidate layups to test (describe how: fixed list, parameter sweep, or optimizer).
  3. Build each layup in ACP on the part geometry and solve it in Workbench.
  4. Score and rank the results (describe the criteria: mass, failure index, deflection).

Validating it

A simulation is only useful if it matches the real part, so I'm testing the same layups in the lab before trusting the tool on anything new.

  • Punch-shear tests on 100 × 100 mm samples: done, from the anti-intrusion plate work.
  • Three-point bend tests: planned.
